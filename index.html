Frame by Frame Help

Pose, add a frame, repeat.

Pull a red hand or foot to bend its limb while the torso stays planted. Turn off Options → Pull joints for classic branch rotation. Shift-click a joint to pin or release it (blue); Alt-drag snaps rotations to 15°. Drag the orange origin to move a figure. Next Frame copies the current pose; thumbnails select an earlier frame. Use the vertical speed control to change playback speed.

File → Create figure opens a blank builder. Select a joint, choose + Line or + Circle, then click to add connected segments. Move drags joints; Snap aligns to existing joints and a 10-unit grid. Name and Save stores a reusable character in the figure picker. File exports a portable figure. Ctrl+Z undoes builder edits. Edit opens an existing figure. The toolbar changes the selected segment's shape, thickness and static state, or hides/restores limbs. Close with × to apply. File → Close without applying discards changes.

File saves/opens local JSON projects and exports a frame PNG. Space plays; arrow keys navigate; Ctrl+Z undoes. Your previous JSON projects still open.
