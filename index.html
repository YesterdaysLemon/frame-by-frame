Frame by Frame Help

Pose, add a frame, repeat.

Drag red joints to pose. Drag the orange origin to move a figure. Next Frame copies the current pose; thumbnails select an earlier frame. Use the vertical speed control to change playback speed.

Edit opens the Stick Figure Builder. Drag its joints to change lengths. The toolbar changes the selected segment's shape, thickness and static state, or hides/restores limbs. Close with × to apply. File → Close without applying discards changes.

File saves/opens local JSON projects and exports a frame PNG. Space plays; arrow keys navigate; Ctrl+Z undoes. Your previous JSON projects still open.
