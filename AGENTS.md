# Frame by Frame design direction

Preserve the owner's classic desktop design language in all future features:

- Gray Windows-classic-style surfaces, square beveled controls, compact Tahoma/Arial text, and narrow menu bars.
- Blue gradient title bars on tool windows; gray title bar on the main editor. New windows should look like the existing builder and library.
- No rounded cards, oversized headings, modern dashboard navigation, or replacement design systems.
- The figure builder is a viewport-level modeless window above the app's other modeless windows. Never put it back inside a canvas clipping region. It must drag over menus, timeline and sidebars.
- Preserve existing animation and library saves. Validate imported data, and keep all character/rig/library content local unless the owner explicitly requests a network feature.
- Verify changes in a real browser at the reference size (665 × 570), a wider desktop, and a narrow viewport. Check interactions as well as appearance.

Reference screenshots in this repository are original-rendered app captures, not redistributed screenshots/assets from the inspiration application.
